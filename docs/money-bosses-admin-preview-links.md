# Money Bosses Admin — development preview

[Open the working Money Bosses Command Center preview](https://3004-ikxczl2n4gl61dsmk7yof-a46ef21c.us5.manus.computer/admin/money-bosses/preview)

This is a development-only preview of the existing Command Center module. It shows no customer records and creates no backend records. It is not the live dashboard and does not bypass authentication on the real admin route.

To test: open **Archive Content**, choose **Use existing test clip**, **Save local draft**, select artwork and the draft, **Assign local draft**, then **Play with Sound**. Planned release dates are metadata only. Everything remains local to this preview.

The protected route is [Money Bosses Admin — existing login required](https://3004-ikxczl2n4gl61dsmk7yof-a46ef21c.us5.manus.computer/admin/money-bosses). A real staging login is not configured; anonymous access correctly returns to login.

The HTTPS preview is temporary development access and depends on this sandbox remaining available. It is not a production QR destination. No production changes have been deployed.
