# ATL IMPACT — Map-First Prototype V3

Independent preview for Kenn Collier. County map with 159 selectable counties, historical CDC MIOV mortality data, and new Georgia DPH OASIS partial firearm injury-care module: accidental-shooting ER visits not ending in hospital admission, 2019–2025 (source via no-key Georgia Civic Data). Numbers are ER **visits**, by county of patient residence, not unique survivors, not all nonfatal shootings, and not firearm assaults. Broad nonfatal injury counts are not connected. Visit https://dph.georgia.gov/faster-ga for broader public firearm injury surveillance.

Preview uses dedicated Render service `atl-impact-intelligence-demo`, branch `prototype/atl-impact-2026-v1`, auto-deploy disabled. Deployment package remains `site.zip`: `unzip -oq site.zip -d app && test -f app/server.js`, `node app/server.js`. No production Turbo Response code modified. Earlier versions retained in git commit history. See package README and `test-injury.js` for source notes and verification tests. No invented counts or auto-monitoring.
