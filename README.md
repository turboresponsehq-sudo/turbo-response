# ATL IMPACT · Map-First V2

This isolated demonstration now supports public CDC MIOV firearm death and firearm homicide historical county data (2019–2024) via the free, public Georgia Civic Data read-only API, annual year selection, a six-year county trend view, and the existing 159-county map with House-district overlay when Census geometry is accessible. Suppressed county counts are withheld, not zero, and 2025–2026 data is pending. New research is still manually verified; no automated incident monitoring or publishing.

The site remains packaged as `site.zip`, built into `app/` by Render, and uses the unchanged standalone preview service with auto-deploy disabled. Original code remains in branch commit history. See package `README.md` for sources, licenses, and limitations. Do not merge to main.
