# ATL IMPACT — Map-First V4

Working map prototype on dedicated Render service `atl-impact-intelligence-demo`. V4 fixes mobile county selection by automatically scrolling the selected county panel into view; includes accessible retry for external mortality endpoint failures. Data source failures no longer silently look like zeros: a small set of separately sourced and documented county-year mortality examples is stored as a fallback, explicitly marked 'documented examples only'. It is not a statewide complete dataset. Partial accidental-shooting emergency-visit data and 2019–2024 history remain source-backed when available. County figures and annual source definitions are shown with caveats. The live source and current 2026 district boundaries still require external service availability.

Standalone branch `prototype/atl-impact-2026-v1`, auto-deploy disabled. Site ZIP unpacked to app/ during build (`unzip -oq site.zip -d app && test -f app/server.js`) and started via `node app/server.js`. The unrelated Turbo Response production app is not modified. Prior versions retained in branch history.
